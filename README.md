## Tujuan
Menggunakan fungsi, parameter, return value, dan scope untuk membuat program modular.

## Cara Menjalankan
python3 praktik/utilitas_matematika.py
# atau di Windows:
py praktik/utilitas_matematika.py

## Struktur Fungsi
- `luas_persegi_panjang(p, l)`: Menghitung luas persegi panjang menggunakan parameter panjang dan lebar.
- `luas_segitiga(a, t)`: Menghitung luas segitiga menggunakan parameter alas dan tinggi.
- `jumlah_n(n)`: Menghitung jumlah angka dari 1 sampai n menggunakan perulangan.
- `faktorial(n)`: Menghitung nilai faktorial dari n.
- `tampilkan_menu()`: Menampilkan pilihan menu interaktif.

## Hasil Pengujian
- Luas persegi panjang (8, 5) -> 40
- Luas segitiga (10, 6) -> 30.0
- Jumlah 1 sampai 10 -> 55
- Faktorial 5 -> 120
